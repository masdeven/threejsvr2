🧠 VR-Based Computer Hardware Learning Application

(WebXR + Three.js)

An interactive WebXR-based learning application for exploring computer hardware in 3D. Developed using Three.js and WebXR with the Multimedia Development Life Cycle (MDLC) methodology, this application enables learners to study computer hardware components interactively through an immersive browser-based experience — without requiring expensive VR devices.

🚀 Features

  • Interactive 3D visualization of computer hardware
  • Web-based VR mode (WebXR)
  • Audio narration using AI-generated voice
  • Lightweight, optimized 3D rendering (Draco + KTX2 compression)
  • Responsive controls for desktop and VR devices

🧩 Tech Stack

Category Tools / Frameworks
3D Engine Three.js
XR Support WebXR API
Optimization glTF-Transform, Draco, KTX2
Modeling Blender
Audio GPT-SoVITS (AI TTS), YouTube Audio Library
Hosting Cloudflare Pages / GitHub Pages

🧱 Development Workflow

  1. 3D modeling in Blender (±20% vertex reduction)
  2. Export as .glb format
  3. Optimize using glTF-Transform
    • optimize (simplify structure)
    • draco (geometry compression)
    • ktx2 (texture compression)
  4. Integrate into Three.js + WebXR
  5. Test and deploy on the web
